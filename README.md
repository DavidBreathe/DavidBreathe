# Hi, I'm David

CEO and owner of **[Breathe IT](https://breathe.no)**, a Microsoft consultancy in Stavern, Norway.

We're a small team that ships like a much larger one. AI agents are part of how we run: humans own priorities, decisions and acceptance; agents do much of the planning, coding, testing and review, under guardrails we enforce.

### How we work

We use Claude Code and Codex as teammates, with the right model for each role and shared defaults on every workstation. GitHub is our shared memory: issues and PRs are the record, and every handoff carries scope, commit, acceptance criteria and test evidence. Review and autonomy are bounded, with two reviewers and two rounds per task, and agents work in isolated worktrees with time and cost limits, never push to `main` and flag real blockers as `needs-human`. We favor evidence over claims, with quality gates before UAT, and a skipped or failed check is never reported as passing.
